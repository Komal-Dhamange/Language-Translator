
# 🌍 AI Language Translator (Modern UI)

![Python](https://img.shields.io/badge/Python-3.9+-blue?style=for-the-badge&logo=python)
![CustomTkinter](https://img.shields.io/badge/UI-CustomTkinter-orange?style=for-the-badge)
![AI](https://img.shields.io/badge/Powered%20By-Google%20Translate%20API-green?style=for-the-badge)

A professional, modern, and interactive Desktop Application built using Python and CustomTkinter.

This application allows users to translate text into multiple global languages with a beautiful dark-themed UI and smart AI-powered translation features.

---

# ✨ Features

- 🌐 Multi-Language Translation
- 🎨 Modern Dark UI using CustomTkinter
- ⚡ Fast Translation System
- 📋 Copy Translated Text
- 🤖 Auto Language Detection
- 🔊 Text-to-Speech Support
- 🧠 AI Translation Engine
- 💻 Responsive Desktop Interface

| CustomTkinter | Modern GUI |

🚀 Installation & Setup

1️⃣ Clone Repository

git clone https://github.com/Komal-Dhamange/Language-Translator.git

cd Language-Translator


---

2️⃣ Create Virtual Environment

python -m venv venv

Activate Virtual Environment

Windows

venv\Scripts\activate


---

3️⃣ Install Required Libraries

pip install customtkinter

pip install googletrans==4.0.0-rc1

pip install gTTS pygame pillow

OR install all together:

pip install customtkinter googletrans==4.0.0-rc1 gTTS pygame pillow


---

4️⃣ Run Application

python app.py

🧠 How It Works

1. User enters text.


2. Selects target language.


3. Google Translate API processes translation.


4. Output displayed instantly.


5. User can copy or listen to translated text.
